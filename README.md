# Python Rock Paper Scissors

## Explanation

This project is a simple Rock Paper Scissors game developed using Python. The user selects Rock, Paper, or Scissors, and the computer randomly selects one of the three choices.

## Problem Statement

Create a Python program that allows a user to play Rock Paper Scissors against the computer and determines the winner based on the game rules.

## Features

* User can choose Rock, Paper, or Scissors.
* Computer makes a random choice.
* Determines the winner.
* Handles invalid input.
* Displays both choices and the result.

## How It Works

1. The user enters Rock, Paper, or Scissors.
2. The computer randomly selects a choice.
3. The program compares both choices.
4. The winner is determined according to the rules.
5. The result is displayed.

## Technologies Used

* Python
* `random` module

## Data Structure Used

* List

## Methods Used

* `random.choice()`
* `input()`
* Conditional statements
* String methods

## Program Flow

1. Start the program.
2. Create a list containing Rock, Paper, and Scissors.
3. Take the user's choice.
4. Generate the computer's choice.
5. Compare the choices.
6. Display the result.
7. End the program.

## Sample Input

```text
Enter your choice (rock/paper/scissors): rock
```

## Sample Output

```text
Computer's choice: scissors
You win!
```
